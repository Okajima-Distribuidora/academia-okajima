# Academia Okajima

1. **Academia atualizada** — esta é a nova versão da Academia Okajima, com uma experiência renovada para assistir, acompanhar e organizar os conteúdos de aprendizagem.

2. **Tecnologias utilizadas** — o projeto é desenvolvido com Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, Base UI, Prisma e MySQL.

3. **Em desenvolvimento** — a plataforma continua em evolução, com novas funcionalidades e melhorias sendo implementadas continuamente.
